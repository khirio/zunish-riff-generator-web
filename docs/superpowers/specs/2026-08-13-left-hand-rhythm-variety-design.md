# 左手リズムパターンの多様化 — 設計書

## 背景・目的

左手伴奏（`AccompanimentPattern`）は現在「全音符ブロックコード」と「8分音符×8のブロークン」の2種類しかなく、原作でよく見られる以下のリズムパターンを再現できない。

1. 付点2分(2.5拍)→16分×4→8分
2. 16分/32分とtresilloの複雑な組み合わせ

（8分のシンコペーションは右手・メロディ側の担当とし、左手からは対象外とする。左手は常に小節線に合わせて区切る。）

これらを表現できるよう、左手伴奏パターンのデータモデルと生成ロジックを拡張する。**右手（`content/rhythms.py`、スケールウォーク用）は対象外。**

## 決定事項の要約

- シンコペーション（次の小節の和音を先取りする、あるいは小節線をまたいで発音する）は左手では実装しない。左手のすべてのノートは、現在の小節・現在の和音の範囲内で完結する。これにより「1小節=独立して生成できる」という既存アーキテクチャ・再生系（`Player`）・既存テストの不変条件（`0 <= start_beat`, `start_beat + duration_beat <= BEATS_PER_BAR`）を一切変更せずに済む。小節をまたぐ・次の和音を先取りするアンティシペーションは、右手（メロディ）側で別途対応する想定であり、本設計のスコープ外。
- 「付点2分」は実測では2.5拍（付点2分=3拍ではない）。2.5拍 + 16分×4(1拍) + 8分(0.5拍) = ちょうど4拍で1小節に収まる。末尾の8分音符は現在の和音のトーンを弾く（先取りしない）。
- 具体的な音選び（どのコードトーンをどの順で弾くか）は、原曲の厳密な採譜ではなく、説明された特徴を再現する代表的なパターンとして設計する。

## データモデルの変更（`content/accompaniment.py`）

### 時間分解能の変更

`eighth_note_durations`（8分音符単位、1小節=8）を **`thirty_second_note_durations`（32分音符単位、1小節=32）** にリネーム・変更する。

理由: 16分(=2)・32分(=1)・付点4分(=12)・2.5拍(=20)など、必要な音価がすべて整数で表現できる。右手の`rhythms.py`は8分単位のまま変更しない（別レジストリなので混在による実害はない）。

既存パターンの変換:
- `block_chord`: 変更なし（`kind="block"`は時間分解能を使わない）
- `broken_root_fifth_third_fifth`: `(1,1,1,1,1,1,1,1)` → `(4,4,4,4,4,4,4,4)`

### レスト（無音）の許容

`note_order`の要素型を `int | None` に拡張する。`None`は「その区間は発音しない（時間だけ進める）」ことを意味する。今回追加する2パターンでは実際には使わないが、将来的な柔軟性のために型として許容しておく（`_left_hand_events`側でNoneをスキップするだけの軽微な変更）。

### バリデーション

`AccompanimentPattern.__post_init__`（または既存テストパターンに準拠する形）で、`kind == "broken"` のとき `len(note_order) == len(thirty_second_note_durations)` を保証する（既存テストの移植）。

## 生成ロジックの変更

### `generator.py`

`generate_slot`のシグネチャは変更しない（次小節の情報は不要になったため）。`_left_hand_events`は、`note_order`の要素が`None`の場合に`NoteEvent`を生成せず時間だけ進めるようにする点のみ変更する。

### `director.py`

変更なし。左手が次の和音を先取りする必要がなくなったため、1小節先読みの仕組みは不要。`bars()`は現状の「1小節ずつその場で決めて`generate_slot`を呼ぶ」実装のままでよい。

## 追加する具体的パターン（32分音符単位、1小節=32）

`note_order`のインデックスは既存と同じ規則: 0=root, 1=3rd, 2=5th（`len(voicing)`で mod ラップ）。両パターンとも小節線をまたがず、現在の和音のみを使う。

### ① 付点2.5拍→16分×4→8分 (`dotted_walk`)

```
root(20=2.5拍) | 16th 16th 16th 16th (2×4=1拍, root-3rd-5th-root) | 8th(4=0.5拍, root)
```
- `note_order = (0, 0, 1, 2, 0, 0)`
- `thirty_second_note_durations = (20, 2, 2, 2, 2, 4)`

### ② tresillo複合型（16分/32分装飾） (`tresillo_ornamented`)

```
[32nd 32nd 装飾]+sustain(1+1+10=12=1.5拍) | sustain(12=1.5拍,5th) | 16th×4(2×4=1拍,root-3rd-5th-root)
```
- `note_order = (0, 2, 0, 2, 0, 1, 2, 0)`
- `thirty_second_note_durations = (1, 1, 10, 12, 2, 2, 2, 2)`

既存の`block_chord`・`broken_root_fifth_third_fifth`は残し、新規2パターンを追加登録する（`weight`はいずれも既存パターンと同程度、1.0前後で登録し、実際に鳴らして調整可能とする）。

## テスト方針

- `tests/test_content_registries.py`:
  - `sum(pattern.thirty_second_note_durations) == 32`（`kind == "broken"`のパターンのみ）を検証するテストを追加。
  - `len(note_order) == len(thirty_second_note_durations)`（`kind == "broken"`のパターンのみ）を検証するテストを追加。
- `tests/test_generator.py`:
  - `None`を含む`note_order`のノートがスキップされ、時間だけ進むことを検証するテストを追加。
  - 既存の`event.start_beat + event.duration_beat <= BEATS_PER_BAR`不変条件は変更しない。
- `tests/test_director.py`: 変更なし（`Director`自体に変更がないため）。

## 影響範囲外（今回やらないこと）

- 右手（`content/rhythms.py`、スケールウォーク生成）の分解能変更はしない。
- シンコペーション・アンティシペーション（次の小節の和音を先取りする、小節境界を越えて発音する）は左手では実装しない。右手（メロディ）側で別途対応する想定。
- レスト（`None`）を実際に使うパターンの追加は今回のスコープ外（型としては許容するが、具体例は追加しない）。
